# ADR 0004 · 프리셋에 신호 순서를 저장하고 기존 슬롯을 다시 연결한다

Virtual Rig와 Audio Sandbox는 하나의 프리셋을 공유한다. 입력 게인과 마스터를 양 끝에 두고 여섯 페달, NAM 모델, 캐비닛 IR을 한 번씩 배치한다. 프리셋 버전 2의 `order`에서 누락·중복·알 수 없는 슬롯을 거부한다. 버전 1은 읽을 때 원래 순서를 부여하고, 사용자가 저장할 때 버전 2로 기록한다.

그래프 전체를 복제해 교차 페이드하면 두 NAM 처리기와 두 컨볼버가 동시에 실행될 수 있고, 로드한 모델과 딜레이 피드백을 새 그래프로 옮겨야 한다. 그래서 기존 노드를 유지하고 Wet 출력이 페이드아웃된 뒤 슬롯 사이의 연결만 교체한다. 딜레이 내부 피드백과 NAM Worklet의 연결은 유지한다. 이 방식은 편집 순간 Wet 음량이 잠시 작아지며, 메인 스레드가 바쁘면 음량 복귀가 늦어질 수 있다.

실시간 재생과 WAV 렌더가 같은 그래프 생성자를 쓴다. Chrome에서 왜곡 전후로 EQ를 옮겼을 때 두 출력의 RMS가 같은 방향과 크기로 바뀌는지, 원래 순서와 Dry 출력이 복원되는지 확인한다. 실제 기타로 전환음을 듣는 항목은 실기기 검증에 남긴다. [검증 기록](../testing/software-test.md)
