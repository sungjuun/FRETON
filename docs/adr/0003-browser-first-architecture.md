# ADR 0003 · PC 브라우저와 로컬 저장부터 제공한다

상태는 채택이다. Phase 0은 Windows와 macOS에서 장비 없이 열 수 있고, 외부 계정 없이 실제 오디오를 확인할 수 있어야 한다.

처음부터 데스크톱 셸을 포함하는 방법과 백엔드 기반 저장을 비교했다. 설치형 앱은 장치 통합 여지를 주지만 서명·패키징·업데이트 경로가 필요하다. 서버 프리셋은 동기화가 쉽지만 계정과 운영 데이터가 필요하다.

Vite 기반 정적 앱과 IndexedDB를 채택했다. JSON 내보내기로 다른 브라우저로 이동할 수 있다. 로컬 파일은 사용자가 선택하며 저장된 모델·IR 참조는 재선택 때 확인한다. 오디오 코드에 React 의존성을 두지 않아 후속 데스크톱 셸에서 재사용할 수 있다. 원본 파일 권한과 사이트 데이터 삭제에 따른 복구는 사용자가 관리한다.
