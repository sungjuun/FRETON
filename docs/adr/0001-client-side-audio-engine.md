# ADR 0001 · 실시간 처리를 클라이언트에 둔다

상태는 채택이다. 기타 입력은 라우팅·연주 반응이 중요하고 파일과 장치 신호에는 사용자 데이터가 포함된다.

검토한 대안은 브라우저 Web Audio 그래프, 서버 스트리밍 DSP, 네이티브 전용 엔진이다. 서버 처리는 네트워크 왕복과 업로드 권한, 서비스 운영 비용을 더한다. 네이티브 엔진은 드라이버 제어와 최적화에 유리하나 회사 환경에 별도 설치가 필요하다.

브라우저가 실시간 그래프와 장치를 소유하도록 결정했다. 서버 없이 파일·합성 신호로 개발하고 OfflineAudioContext에서 같은 DSP를 검증할 수 있다. 대가로 실제 기기·브라우저의 레이트, 버퍼, 지연 제약을 받는다. 물리적 왕복 지연은 QME-50에서 따로 측정한다.
