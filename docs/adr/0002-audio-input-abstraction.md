# ADR 0002 · 교체 가능한 입력과 공통 그래프

상태는 채택이다. 회사의 파일과 테스트 신호에서 얻은 결과를 집의 USB 기타 입력과 비교하려면 이펙트 경로가 같아야 한다.

입력 종류별로 전체 그래프를 복제하는 방법, React 컴포넌트가 노드를 소유하는 방법, 전용 소스가 엔진 입력에 연결되는 방법을 비교했다. 그래프 복제는 파라미터·보호단의 불일치를 만들 수 있다. UI 소유 방식은 라우팅 시 컴포넌트 수명과 연주가 묶인다.

세 입력 구현은 공통 대상 노드로 연결하고 `disconnect()`로 해제한다. 파일 재생 위치와 라이브 채널 선택은 각 구현에 둔다. 단일 엔진이 활성 소스를 배타적으로 소유한다. 비동기 접근에 따른 복잡성은 요청 번호와 늦은 스트림 폐기로 처리하고 브라우저 회귀 검사로 검증한다.
