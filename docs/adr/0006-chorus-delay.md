# ADR 0006 · Chorus에 변조 지연선을 사용한다

Chorus는 원음을 유지하면서 짧은 지연음의 음높이를 주기적으로 흔들어 겹친다. 기존 실시간·오프라인 그래프가 공유하는 Web Audio DelayNode의 지연 시간에 사인파 OscillatorNode를 연결했다. 별도 버퍼와 보간기를 작성하는 워크릿도 검토했으나, 이 효과는 브라우저 기본 노드로 구현할 수 있고 추가 모듈을 로드할 필요가 없다.

기준 지연은 15 ms이며 Depth가 최대 8 ms여도 지연 시간은 양수다. Rate와 Depth를 편집하면 같은 발진기의 주파수·진폭을 조절한다. 모노 입력은 모노로, 스테레오 입력은 좌우 레벨과 극성을 유지한 채 같은 지연 곡선을 따른다. 발진기는 처음 활성화할 때 시작해 재배치와 바이패스 중에도 위상을 이어가고, 그래프 폐기 때 정지한다. 각 오프라인 렌더는 독립된 발진기로 시작한다.

버전 1~3 프리셋은 기존 처리 순서를 보존하고 Delay 직전에 꺼진 Chorus를 삽입한다. Wet 렌더 길이에는 활성 Chorus의 기준 지연과 Depth를 더한다. 임펄스로 지연 시간과 마지막 표본의 출력을, 연속 사인파로 실제 파일 재생과 내려받은 WAV를 검증했다. [소프트웨어 검증](../testing/software-test.md)
