# ADR 0005 · Noise Gate의 레벨 검출과 게인 조절을 오디오 스레드에서 처리한다

Noise Gate는 짧은 피킹을 감지하면서 음 끝의 작은 진폭 변화에도 안정적으로 닫혀야 한다. UI 타이머로 미터를 읽으면 메인 스레드의 상태에 따라 검출 시점이 달라지고 오프라인 렌더에 같은 시계를 쓸 수 없다. 샘플에 임계값만 적용하는 WaveShaper는 열린 음의 영점 부근까지 잘라낸다. 실시간·오프라인 그래프에서 같은 AudioWorklet을 실행하기로 했다. [Web Audio의 AudioWorkletProcessor](https://www.w3.org/TR/webaudio-1.0/#AudioWorkletProcessor)

각 표본에서 채널별 절댓값 중 최댓값을 취한다. 검출기는 피크를 즉시 따르고 8 ms 시정수로 감쇠한다. 여는 임계값보다 6 dB 낮은 지점을 밑돈 시간이 Hold를 지나면 닫는다. Attack과 Release는 게인이 0과 1 사이의 전체 범위를 선형으로 이동하는 시간이다. 좌우 채널은 같은 게인을 사용한다.

실시간 엔진은 시작할 때 로컬 워크릿을 등록하고 게이트를 처음 켤 때 처리 노드를 만든다. 등록 또는 처리 실패 시 해당 슬롯을 우회하고 화면에 알린다. Wet 렌더는 활성 게이트가 필요할 때 워크릿을 준비하고, 실패하면 오류를 반환한다. 기본 프리셋과 버전 1·2 프리셋은 게이트가 꺼진 상태로 시작한다. 새 파일은 버전 3에 상태·파라미터·순서를 기록한다. [검증 결과](../testing/software-test.md)
