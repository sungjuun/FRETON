# ADR 0008 · 사용자가 고른 NAM 파일을 이 브라우저에 보관한다

Virtual Rig에서 이전에 사용한 캡처를 다시 선택할 수 있도록 IndexedDB에 모델 라이브러리를 둔다. **라이브러리에 모델 추가**로 고른 파일만 보관한다. **NAM 파일 선택**은 기존처럼 현재 세션에 연결한다.

프리셋마다 가중치를 넣는 방법은 JSON 한 개로 이동할 수 있지만 같은 캡처를 쓰는 프리셋 수만큼 용량이 늘어난다. 파일명만 보관하면 저장 공간은 줄지만 매 세션마다 원본을 찾아야 하고 동명 파일을 구분하기 어렵다. 별도 데이터베이스에 SHA-256으로 한 번 저장하면 이전 프리셋의 형식을 유지하면서 목록에서 같은 캡처를 다시 연결할 수 있다.

목록 정보와 파일을 한 트랜잭션으로 추가·삭제한다. 목록을 열 때는 메타데이터만 읽는다. 모델 적용 시 원본과 같은 로더로 지문·레이트를 검증하고 Worklet 로딩에 성공한 뒤 슬롯을 바꾼다. 사용자가 삭제한 모델은 현재 연주가 끝날 때까지 엔진에서 사용할 수 있다. 사이트 데이터 삭제와 다른 기기로 이동할 때의 복구에는 원본 파일이 필요하다.

검증 기준은 중복 파일 한 건 저장, 동명 캡처 구분, 새 세션에서 프리셋의 캡처 유형·바이패스 복원, 레이트 불일치 및 늦은 저장소 읽기에서 기존 모델 보존이다. [Chrome 검증 기록](../testing/software-test.md)
