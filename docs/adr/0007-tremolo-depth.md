# ADR 0007 · Tremolo의 Depth를 진폭 감쇠 폭으로 정의한다

Depth 65%에서는 가장 큰 순간에 원음의 100%, 가장 작은 순간에 35%가 통과한다. 처리 경로의 GainNode에 사인파 발진기를 연결해 이득을 0~1로 움직이고, 기존 페달의 원음·처리음 혼합 비율로 Depth를 조절한다. 별도 워크릿이나 메인 스레드 타이머 없이 실시간 처리와 Wet WAV가 같은 그래프를 실행한다.

발진기는 처음 페달을 켤 때 시작한다. 속도를 바꾸거나 같은 그래프에서 페달을 옮겨도 위상을 이어 가며, 그래프를 폐기할 때 정지한다. 양쪽 채널에 같은 이득을 곱하므로 좌우 밸런스를 유지하고 WAV 길이도 보존한다. 각 오프라인 렌더는 자체 발진기를 처음부터 시작한다.

이전 프리셋에는 Delay 바로 앞에 꺼진 Tremolo를 넣는다. 버전 5는 편집한 위치·활성 상태·파라미터를 저장한다. [측정 및 호환성 검증](../testing/software-test.md)
