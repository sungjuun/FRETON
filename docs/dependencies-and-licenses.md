앰프·페달 외관은 프로젝트 CSS와 SVG로 그린다. 합성 기타, 생성 리버브, 기본 프리셋, 시험 WAV와 선형 모델은 프로젝트 내 알고리즘·계수로 만든다. 사용자의 오디오 파일, IR, NAM 가중치는 별도 권리 대상이다. 외부 캡처나 상용 녹음·로고를 기본 콘텐츠로 묶지 않았다.
