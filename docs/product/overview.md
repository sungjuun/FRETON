# 제품 개요

FRETON은 기타 입력에서 출력까지의 신호를 사용자가 직접 듣고 편집하는 디지털 기타 스튜디오다. 일렉기타 입문자는 기본 톤을 선택해 시작하고, 커버 연주자는 파일 또는 인터페이스 입력으로 같은 프리셋을 반복 시험할 수 있다.

Phase 0의 완료 기준은 장비 없는 Windows Chrome에서 원음과 처리음을 실제로 비교하고, 원하는 설정을 저장해 새 세션에서 복구하는 것이다. 집에서는 MacBook, 일렉기타, SONICAKE Matribox 1, 유선 헤드폰으로 동일한 엔진을 검증한다.

첫 진입 화면은 Virtual Rig다. Audio Sandbox는 파일·신호·미터·진단을 한 화면에서 제공하고 Settings는 장치 설정을 제공한다. 브랜드와 슬로건은 `apps/web/src/config/brand.ts`에서 관리한다. [기능 명세](feature-specification.md) · [로드맵](roadmap.md)
