## v0.1.0 NAM 모델 라이브러리

Virtual Rig·Audio Sandbox의 NAM 슬롯에서 .nam 파일을 목록에 추가하고, 요구 레이트와 캡처 유형을 확인해 적용하거나 목록에서 삭제한다. 목록 관리에는 오디오 엔진이 필요하지 않다. 같은 파일을 다시 추가하면 기존 항목을 선택한다. 프리셋을 다시 열면 라이브러리에서 지문이 일치하는 모델을 선택해 보여 주며, 사용자가 적용할 때 저장된 활성 상태와 캡처 유형을 복원한다. 목록에서 삭제해도 현재 연주 중인 슬롯과 기존 프리셋은 유지된다.

## v0.1.0 연주 중 전환

앰프 헤드의 신호 경로는 전체 Bypass와 Dry 선택을 우선 표시한다. Wet에서는 연결된 NAM 이름 또는 기본 DSP를 표시하고, 활성 모델이 누락된 프리셋은 재연결 안내를 제공한다. 파일 재생 중 프리셋·모델을 바꿔도 재생 위치가 이어진다. 입력 설정·프리셋 관리·모델 라이브러리를 Esc나 닫기 버튼으로 닫으면 해당 창을 열었던 컨트롤로 포커스가 돌아간다.

라이브 입력 연결을 기다리는 동안 요청을 취소하거나 다른 입력을 고를 수 있다. 취소 뒤 늦게 도착한 스트림의 트랙은 해제하며 늦은 거부 응답은 새 입력에 오류를 표시하지 않는다. 사용자가 현재 요청을 거부한 경우에는 권한 안내를 표시하고 다시 연결할 수 있다.
