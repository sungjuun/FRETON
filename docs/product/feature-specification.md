# v0.0.1 기능 명세

| 사용 흐름   | 실제 동작과 경계                                                                                                                                                                          |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 엔진 시작   | 사용자 조작으로 interactive AudioContext 생성, 낮은 Master, 선택한 소스 연결. 중지 시 스트림·노드·컨텍스트 해제. 재시작은 라이브 재연결을 요구한다.                                       |
| 테스트 입력 | Sine, Square, Triangle, White Noise, Impulse, Frequency Sweep, Silence, 별도의 Karplus–Strong 합성 기타. 주파수와 입력 레벨 조절.                                                         |
| 파일 입력   | 로컬 선택·드롭, 브라우저 코덱 디코딩, 파형·시간·파일 정보, 재생·일시정지·정지·탐색·반복·해제.                                                                                             |
| 라이브 입력 | 장치 목록·권한·명시적 연결, 트랙 설정·종료, 지원 채널 선택, 모니터링과 지원 출력 선택. 파일 및 생성 입력과 배타적이다.                                                                    |
| Virtual Rig | 마우스·키보드 노브, 개별 페달 활성화·편집, 머리판 Gain/EQ/Master, 전체 Bypass, Dry/Wet, NAM·IR 슬롯.                                                                                      |
| 프리셋      | Studio Clean, Warm Clean, British Crunch, Indie Drive, Modern High Gain, Ambient Lead. 편집 중 새 프리셋 선택은 선택한 설정으로 즉시 교체한다. 기본 프리셋을 저장하면 개인 복사본이 된다. |
| 저장·교환   | 브라우저 IndexedDB, 즐겨찾기·이름 변경·복제·삭제, JSON 가져오기·내보내기. 가져온 프리셋에 새 ID를 주고 모든 필수 파라미터를 검증한다.                                                     |
| 분석·진단   | 입력/출력 각각 파형·스펙트럼, RMS·Peak dBFS, 클립, 실제 장치와 채널, 상태, 샘플레이트, 브라우저 지연, Worklet/WASM 지원 및 최근 오류.                                                     |
| 파일 출력   | 기본 DSP, IR, 입력 및 마스터 게인과 보호단을 공유한 OfflineAudioContext. WAV PCM16. 실시간 라이브 입력 녹음과 NAM 오프라인 렌더는 후속 검증 대상이다.                                     |

Matribox 제어 프로토콜, 학습·추천, 계정, 커뮤니티, 녹음 스튜디오와 서버 기능은 장기 로드맵에 속한다. 이 버전의 사용자 저장 공간은 현재 브라우저 프로필이다. [검증 범위](../testing/software-test.md)
